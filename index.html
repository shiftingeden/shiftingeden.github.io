Technology

Write once, ship to every app

The miner apps share one device-integration approach: each protocol is implemented once, then ported across the family. Every change is tracked in a shared changelog with a per-app port-status matrix, so all three stay in sync.

Safety · Security · Privacy

Trust is the product

Miners are rightly wary of software that touches their hardware or their earnings. The whole family is built so there's nothing to trust us with.

No backend, by design

There are no TechBitsMix servers. Apps talk directly to miners on the local network, or directly to a pool's own API over HTTPS.

Data Not Collected

Every app carries Apple's “Data Not Collected” privacy label: no analytics, ads or third-party SDKs.

Secrets stay on-device

Pool API keys live in the iOS Keychain; optional Face ID lock. Sync uses the user's own private iCloud.

Read-only where money is involved

PoolMonitor cannot move funds: no wallet, withdrawals or payout changes, and it only uses read-only keys.

Safe automation

Auto-recovery is opt-in, attempt-capped, and only uses each device's official settings API.

No accounts

Nothing to sign up for, nothing to leak. For an acquirer, there's no user database to secure or migrate.
